# ParkDesk 화면

아이패드 Safari가 **보내는 쪽**, 테슬라 내장 브라우저가 **받는 쪽**입니다. 아이패드 페이지가 직접 그린 화면을 테슬라의 보조 디스플레이로 보냅니다.

두 기기는 **갤럭시 휴대폰 핫스팟** 같은 Wi-Fi에 같이 붙습니다. 영상은 LAN 안에서 직접 갑니다. **TURN/릴레이 서버는 쓰지 않습니다.** `iceServers` 는 공개 STUN `stun:stun.l.google.com:19302` 만 있습니다.

시그널링만 PeerJS 공개 브로커 `0.peerjs.com` 을 씁니다. 테슬라 브라우저는 사설 IP 주소창 접속을 막는 경우가 있어서, 페이지 자체는 공개 HTTPS(GitHub Pages)로 엽니다.

주차(P) 상태에서만 사용하세요. 주행 중에는 열지 마세요.

## 준비

1. 차량을 **주차(P)** 합니다.
2. 갤럭시에서 **모바일 핫스팟**을 켭니다. 회사 PC의 Windows 핫스팟은 쓰지 않습니다.
3. **아이패드**와 **테슬라**가 그 핫스팟 Wi-Fi에 연결되게 합니다. 핫스팟의 클라이언트 격리(AP 격리)는 끄세요. 켜져 있으면 기기간 직접 통신이 막힙니다.
4. 두 기기 모두 같은 공개 HTTPS 주소를 엽니다. 예: `https://<계정>.github.io/<저장소>/`

## 검사 절차

1. 아이패드 Safari에서 페이지를 열고 **iPad (보내는 쪽)** 을 누릅니다. 큰 **페어링 코드**가 나옵니다.
2. 테슬라 브라우저에서 같은 주소를 열고 **테슬라 (받는 쪽)** 을 누른 뒤, 코드를 입력하고 **연결**을 누릅니다.
3. 테슬라에 아이패드 캔버스가 보이면 경로가 된 것입니다. **정보**를 누르면 해상도, fps, 비트레이트, RTT, 선택 쌍(local/remote가 host인지 srflx인지)이 나옵니다. **전체 화면**은 탭으로도 켜집니다.
4. 아이패드에서 내용을 하나씩 바꿉니다.
   - **테스트 패턴**: 시계와 프레임 번호가 움직입니다. 끊김과 지연을 봅니다.
   - **화이트보드**: 손가락이나 Apple Pencil로 그립니다.
   - **메모**: 글을 입력하면 큰 글씨로 테슬라에 보입니다.
   - **사진**: 사진 앱에서 고른 이미지를 화면에 맞춥니다.
5. 해상도는 1920×1200이 기본입니다. 테슬라 실측(CSS 1306×816, dpr 1.96)에 가깝게 보려면 **2560×1600** 을 고릅니다. **1280×800** 은 더 가벼운 시험입니다.

아이패드는 화면 전체를 캡처하지 않습니다. Safari에 `getDisplayMedia`가 없어서, 이 페이지의 `<canvas>`만 `captureStream(30)` 으로 보냅니다.

노트북에서 창 공유가 필요하면 첫 화면 아래 **노트북 화면 공유 (이전 방식)** 을 씁니다. 그 모드는 `getDisplayMedia`가 있는 브라우저용입니다.

## 실패하면 보낼 것

1. 테슬라에 **사진으로 남길 요약**이 뜨면 그 칸을 휴대폰으로 찍습니다. WebRTC, H.264, ICE 상태, 선택 쌍이 들어 있습니다.
2. 아이패드에서 **결과 JSON 복사** 또는 **JSON 파일로 저장**을 누릅니다. `{ sender, tesla }` 한 덩어리이고, 테슬라가 DataChannel로 보낸 결과도 들어 있습니다. 테슬라의 **iPad로 결과 보내기**는 연결이 된 뒤 자동으로 한 번, 후보 쌍이 잡히면 한 번 더 보냅니다.
3. **정보** 오버레이의 경로가 `host` 인지 `srflx` 인지를 같이 적습니다. `relay`가 보이면 안 됩니다. 이 페이지는 TURN을 넣지 않습니다.

브로커만 잠시 끊기면 페어링 코드는 유지하고 같은 ID로 다시 붙습니다. 그때는 사진 요약을 띄우지 않습니다.

## 호스팅

파일은 저장소 **루트**에 있습니다. GitHub Pages는 `main` / `/ (root)` 로 두면 됩니다. `.nojekyll` 이 있어서 Jekyll을 거치지 않습니다. 자산 경로는 상대 경로입니다.

로컬 확인:

```bash
python3 -m http.server 8080
```

`http://127.0.0.1:8080/?role=ipad` 와 `http://127.0.0.1:8080/?role=tesla` 를 엽니다. 로컬 HTTP는 테슬라 검사용이 아닙니다.

## 파일

- `index.html` — 역할 선택, iPad 캔버스, 테슬라 비디오
- `styles.css` — 큰 버튼, 어두운 테마
- `app.js` — 페어링, 캔버스 스트림, 통계, 결과 JSON
- `peerjs.min.js` — PeerJS 1.5.4 (MIT)
- `PEERJS-LICENSE.txt` — 라이선스

## 한계

- TURN이 없으므로, 핫스팟이 클라이언트 간 통신을 막거나 방화벽이 직접 P2P를 막으면 영상은 실패합니다. 시그널링만 되고 화면은 안 나올 수 있습니다.
- 아이패드 OS 화면, 다른 앱, 홈 화면은 보내지 못합니다. 이 페이지 안의 캔버스만 갑니다.
- `canvas.captureStream` 이 없는 오래된 Safari에서는 송신이 되지 않습니다.
- 화면 꺼짐 방지는 Wake Lock이 있을 때만, 그리고 사용자가 한 번 터치한 뒤에 동작할 수 있습니다.
- 캔버스가 가려지면(다른 탭) 그리기를 멈춥니다. 다시 보이면 이어서 그립니다.
- 2560×1600 캔버스는 아이패드에서 무거울 수 있습니다.
